# 🔗 LangChain Essentials Python


This repo contains the hands-on learning as a part of the course [Quickstart: LangChain Essentials - Python
](https://academy.langchain.com/courses/langchain-essentials-python).

Note on API keys: This course is written around the OpenAI API, but the notebooks only use free models available through [OpenRouter](https://openrouter.ai/discover?lane=free). Since OpenRouter exposes an OpenAI-compatible API, you don't need an OpenAI key — just point the client at OpenRouter's base URL and swap in a :free model name, and the existing notebook code works unchanged.
